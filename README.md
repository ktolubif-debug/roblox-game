# roblox-game

Projekt Roblox zsynchronizowany przez Rojo.

## Struktura

- `src/server` -> `ServerScriptService/Server`
- `src/client` -> `StarterPlayer/StarterPlayerScripts/Client`
- `src/shared` -> `ReplicatedStorage/Shared`

Po uruchomieniu Rojo skrypty z tych folderów pojawią się automatycznie w Roblox Studio.
